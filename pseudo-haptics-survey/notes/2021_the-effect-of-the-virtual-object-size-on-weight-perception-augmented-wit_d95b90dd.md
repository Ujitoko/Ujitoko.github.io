The Effect of the Virtual Object Size on Weight Perception Augmented with Pseudo-Haptic Feedback
Jinwook Kim, Jeongmi Lee
2021 IEEE Conference on Virtual Reality and 3D User Interfaces Abstracts and Workshops (VRW) (2021)

物体のサイズがpseudo-hapticsによる重さ感に影響するかを調べた。重さを「感じた」「感じてない」の2択で回答させ、その結果、物体サイズが大きいほどpseudo-hapticsによる重さを感じにくいということだった。物体の視覚特徴によるpseudo-haptics効果を調べた研究という意味では、物体のテクスチャによる効果を調べた[Shimamura-2024](https://ieeexplore.ieee.org/document/10776970/)と関連がある。私はこの論文の実験を真似て、物体サイズとCD比を操作しつつ、重さ感の大きさを5段階の評定法で評価させた実験を色んなバリエーションでやってみたが、その結果としては物体サイズは重さ感の大きさに影響しなかった。重さ感の閾値は物体サイズで変わるが、重さ感の大きさは変わらないということなのかもしれない。
