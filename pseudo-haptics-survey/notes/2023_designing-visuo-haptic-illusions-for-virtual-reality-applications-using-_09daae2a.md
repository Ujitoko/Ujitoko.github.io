1. 論文の解説
- ひとことで：足の実際の探索運動とVR内の表示の方向・縮尺をずらし、床型触覚ディスプレイの形状表現を拡張する研究である。ずれの検出閾値を測定し、視触覚錯覚による滑らかさの表現には利点がある一方、大きな縮尺操作が好まれるとは限らないことを報告した。
- 何をした？：高さの異なるピンで地形を作る床型ディスプレイは、ピンの数や間隔によって提示できる形状が制約される。そこで、足で触れる実物とVR内で見える形状の対応を変え、装置そのものを高密度化せずに表現を広げようとした。具体的には、探索方向を別の方向に対応させる角度操作と、実物と仮想物の長さ・足の移動量の対応を変える縮尺操作を扱っている。
- どう確かめた？：二つのユーザー研究に計32名が参加した。第1研究では16名が実物の木製棒を足で探索し、VR側の角度や縮尺を変えた際に錯覚に気づいたかを、裸足と靴を履いた条件で回答した。検出率に心理測定関数を当てはめ、検出率75%に対応する値などを閾値として求めている。第2研究では、この結果を参考に形状ディスプレイへ錯覚を適用し、表面の解像度の知覚や提示への選好を調べた。
- 分かったこと：75%検出閾値は、角度操作で裸足43.28°、靴あり46.44°、縮尺操作でそれぞれ1.48倍、1.54倍だったが、履物による差は統計的に有意ではなかった。第2研究について著者らは、実際には滑らかでない表面を、より滑らかで高解像度に表現できたと述べている。ただし、1.54倍の縮尺条件で錯覚を用いた半球を好んだ割合は47%であり、閾値を利用した操作がそのまま好ましい体験になるわけではなかった。
- 読むときの注意：検出率75%の閾値は、「その値まで誰もずれに気づかない」という安全な上限ではない。また、棒の探索で得た閾値を半球や歩行全般へそのまま適用することはできず、著者らも足での探索に伴う重心移動が縮尺操作の違和感につながる可能性を挙げている。

2. ファニーな面白ポイント
- 目の付け所：触覚装置の性能だけに頼らず、利用者が何を手掛かりに感覚を判断するかを設計対象にした点。
- ひょうきんな見方：指や手に付ける部品へ、入力と触覚提示の二役を頼んでいる。周辺機器が副業を始めたような設計。
- 論文の作り：一つのデモだけで終わらず、段階を分けた複数の実験で、現象の有無と使える範囲を順に確かめている。
- 系譜：比較対象としては[Visuo-Haptic Illusions for Improving the Perceived Performance of Shape Displays]（https://doi.org/10.1145/3173574.3173724）（2018）が近い。扱う感覚は「形や凹凸・大きさ」、感覚を変える方法は「実物から得る触覚」、使う環境や入力は「VR」。この論文は「見た目の大きさ」、先行研究は「身体の動きの見え方」。

3. メモの下書き
床設置型のピンアレイ形状ディスプレイに視触覚錯覚を組み合わせ、32名の実験で錯覚の閾値と解像度知覚への影響を調べ、装置の物理的制約を超えた地形提示の可能性を示した。触覚装置の性能だけに頼らず、利用者が何を手掛かりに感覚を判断するかを設計対象にした点が面白い。比較対象としては[Visuo-Haptic Illusions for Improving the Perceived Performance of Shape Displays]（https://doi.org/10.1145/3173574.3173724）（2018）が近い。扱う感覚は「形や凹凸・大きさ」、感覚を変える方法は「実物から得る触覚」、使う環境や入力は「VR」。この論文は「見た目の大きさ」、先行研究は「身体の動きの見え方」。効果の有無だけでなく、どの条件で強まり、どこで崩れるかも拾っておきたい。

ピンの高さを制御して地形を作る床上のピンアレイ形状ディスプレイは、ピンの数や間隔等によって提示できる形状が制約される。そこで、足で触れる実物とVR内で見える形状の対応を変え、装置そのものを高密度化せずに表現を広げようとした。コンセプトとしては[Abtahi-2018](https://dl.acm.org/doi/10.1145/3173574.3173724)では手でピンアレイ形状ディスプレイを扱っているが、それの足バージョン。靴の有無の効果も見ている。**ただし実際の動くピンアレイを作って調査したわけではなく、木製の静的な形状を使っているのがユニーク**。実際にピンアレイを作ると工数がかかるのでこういうアナログな方法で検討するのは[Ujitoko-2020](https://pubmed.ncbi.nlm.nih.gov/31751252/)と同じで個人的に好き。
