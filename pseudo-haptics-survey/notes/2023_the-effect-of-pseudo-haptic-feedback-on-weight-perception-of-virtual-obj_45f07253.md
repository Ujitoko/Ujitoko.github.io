1. 論文の解説
- ひとことで：マウスで物体をドラッグするとき、試行中の移動倍率を一定に保っていても重さの印象が生じ、カーソルの表示・非表示によってその印象が変わることを調べた。8名のデータに当てはめたモデルでは、倍率が約1.33より小さい範囲でカーソル非表示の方が重さの知覚指標が高かった。
- 何をした？：問いは、操作の途中で移動倍率を急に変えなくても、移動しにくさを通じて重さを感じさせられるかという点にある。画面上の四角い物体をマウスでドラッグし、カーソルの移動に対して物体がどれだけ進むかを、各試行では一定にする。著者らが静的C/D比と呼ぶ設定であり、カーソル自体を見せる条件と隠す条件も比較する。基準となる入力は実空間でのマウス移動量ではなく、画面上のカーソル移動量である。
- どう確かめた？：8名全員がカーソル表示・非表示の両条件を体験した。4名は非表示から、残る4名は表示から始めた。参加者は、外観が同じ二つの四角形を指定軌道に沿って動かした。一方は倍率1の標準刺激で、もう一方は0.48、0.58、0.69、0.83、1.00、1.20、1.44、1.73、2.08の9段階から無作為に選んだ比較刺激である。各倍率を4回ずつ提示し、表示・非表示それぞれ36試行、1人計72試行を行った。9試行ごとに30秒休めるようにし、倍率と重さ知覚の関係を条件別の単回帰で分析した。
- 分かったこと：倍率が小さいほど重さの知覚指標が高くなる関係が得られた。カーソル表示条件では倍率の効果が有意で（F(1,283)=534.30、p<0.001）、分散の65.4%を説明した。倍率をx、論文の重さ知覚指標をyとする回帰式は、表示時がy=0.81−0.23x、非表示時がy=0.93−0.32xだった。調整済み決定係数はそれぞれ65.3%と70.7%だった。二つのモデルは倍率約1.33で交差し、それより小さい倍率では非表示時の予測値が高く、大きい倍率では関係が逆転した。著者らは、必要な手の移動が増えることによる疲労も重さの印象に寄与すると解釈している。
- 読むときの注意：約1.33という境目は回帰式から得た交点であり、各倍率で表示・非表示に有意差があることを直接示す検定結果ではない。表示条件の回帰では3点の外れ値を除いており、当てはまりの良さは別の参加者に対する予測精度を保証しない。また、疲労を独立に測定した結果や動的な倍率操作との直接比較は示されていないため、疲労が原因であることや、動的方式と同等の効果があることまでは確定できない。

2. ファニーな面白ポイント
- 目の付け所：実際の質量と、利用者が見た目や動きから判断する重さを切り離し、後者だけを設計対象にした点。
- ひょうきんな見方：はかりに載せれば同じでも、持った人の中では別の重さになる。質量保存則の外側で、体感だけがよく動く。
- 系譜：比較対象としては[The Effect of the Virtual Object Size on Weight Perception Augmented with Pseudo-Haptic Feedback]（https://doi.org/10.1109/vrw52623.2021.00170）（2021）が近い。扱う感覚は「重さ」、研究の目的は「感覚の仕組みを確かめる研究」、研究の進め方は「感覚を比べる実験」。この論文は「PC画面」、先行研究は「実際の身体と画面上の身体のずれ・見た目の大きさ」。

3. メモの下書き
コンピュータ側で提示するpseudo-hapticフィードバックが仮想物体の重さ知覚に与える効果を調べた。実際の質量と、利用者が見た目や動きから判断する重さを切り離し、後者だけを設計対象にした点が面白い。比較対象としては[The Effect of the Virtual Object Size on Weight Perception Augmented with Pseudo-Haptic Feedback]（https://doi.org/10.1109/vrw52623.2021.00170）（2021）が近い。扱う感覚は「重さ」、研究の目的は「感覚の仕組みを確かめる研究」、研究の進め方は「感覚を比べる実験」。この論文は「PC画面」、先行研究は「実際の身体と画面上の身体のずれ・見た目の大きさ」。抄録がないため、詳しい仕組みと評価結果は本文を入手してから補いたい。

PC画面上の四角形をマウスでドラッグするとき、カーソルに対する四角形の移動ゲインを変えると重さが変わって感じられるか、さらにカーソルを隠すと効果が強まるかを調べている。デスクトップ環境の場合、通常はマウスに対するカーソルの移動ゲインを操作するが、この研究では見えるカーソルに対する四角形のゲインを操作しており、マウスと四角形（操作対象）の間にカーソルが媒介している変わった構成。カーソルを非表示にすると表示したときと比べて、少し重さ感は強まるという結果だった。これはタッチパネル等でカーソルと操作対象物のズレが見えると、pseudo-hapticsが弱まるという[知見](https://ieeexplore.ieee.org/document/6775491/)と整合的である。
